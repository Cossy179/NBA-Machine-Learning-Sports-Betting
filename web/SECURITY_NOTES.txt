PRODUCTION SECURITY CHECKLIST
============================

RECOMMENDED ACTIONS:
1. Set JWT_SECRET in environment variables
2. Set SECRET_KEY in environment variables  
3. Update CORS origin from * to your domain
4. Enable HTTPS/SSL certificate
5. Set strong admin password

SECURITY FEATURES IMPLEMENTED:
✅ PBKDF2 password hashing with salt (100,000 iterations)
✅ JWT tokens with expiration (8 hours)
✅ Rate limiting (10 attempts per 15 minutes per IP)
✅ Account lockout (5 failed attempts = 30 min lockout)
✅ Input validation and sanitization
✅ SQL injection prevention (prepared statements)
✅ XSS protection headers
✅ CSRF protection ready
✅ Secure session handling
✅ Activity logging and audit trail

PLESK SECURITY SETTINGS:
1. Enable "Restrict access to logs" in Plesk
2. Set up SSL certificate
3. Enable "Hotlink protection"
4. Configure firewall rules
5. Enable "ModSecurity" if available

ENVIRONMENT VARIABLES TO SET IN PLESK:
JWT_SECRET=your-custom-secret-key
SECRET_KEY=your-custom-secret-key
APP_ENV=production

REGULAR MAINTENANCE:

- Update PHP version regularly
- Backup database regularly
- Review user activity logs
- Check for failed login attempts

FILES PROTECTED FROM DIRECT ACCESS:
- web_database.db (database file)

- classes/ directory (PHP classes)
- *.sql, *.log, *.bak files
